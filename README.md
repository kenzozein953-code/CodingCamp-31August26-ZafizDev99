# CodingCamp-31August26-ZafizDev99
Expense &amp; Budget Visualizer aplikasi web mobile-friendly untuk mencatat, mengelola, dan memvisualisasikan pengeluaran berdasarkan kategori. Dibangun dengan HTML, CSS, Vanilla JavaScript, Local Storage, dan Chart.js, dilengkapi monthly summary, sorting transaksi, serta dark/light mode.
